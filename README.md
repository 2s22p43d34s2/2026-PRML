# 2026-PRML Homework3

本仓库为 2026 年《模式识别与机器学习》课程 Homework3 作业代码与报告文件，主题为基于 LSTM 的 PM2.5 浓度预测实验。

## 项目简介

本项目使用空气质量时间序列数据集，基于长短期记忆网络（LSTM）完成 PM2.5 浓度的一步预测任务。实验分别构建了单变量 LSTM 模型和多变量 LSTM 模型，并比较二者在测试集上的预测效果。

其中，单变量 LSTM 模型仅使用历史 PM2.5 浓度作为输入；多变量 LSTM 模型在历史 PM2.5 浓度基础上进一步引入露点、温度、气压、风向、风速、降雪和降雨等气象变量。实验采用 MAE、MSE、RMSE 和 R² 等指标进行评价，并进一步使用 SHAP 方法对多变量 LSTM 模型进行可解释性分析。

## 实验内容

本作业主要包括以下内容：
对空气质量数据进行预处理，包括时间顺序整理、缺失值处理、类别变量编码和归一化处理；
使用滑动窗口方法构造 LSTM 输入样本；
分别训练单变量 LSTM 模型和多变量 LSTM 模型；
使用 MAE、MSE、RMSE 和 R² 比较两类模型的预测性能；
使用 SHAP 方法分析多变量 LSTM 模型中不同输入特征和历史时间步的重要性；
根据实验结果撰写完整实验报告。

## 运行方法
首先运行主实验代码：python Homework3-main.py
该代码会完成数据读取、预处理、模型训练、测试集预测和评价指标计算，并生成预测结果图、损失曲线图以及模型评价结果。
随后运行 SHAP 可解释性分析代码：python Homework3-shap.py
该代码会读取主实验中保存的多变量 LSTM 模型及其对应数据，并生成 SHAP 全局特征重要性图、历史时间步重要性图和特征—时间步热力图。

## 实验结果概述
实验结果表明，单变量 LSTM 模型能够较好地跟踪 PM2.5 浓度的整体变化趋势，说明历史 PM2.5 浓度本身具有较强的短时预测信息。在此基础上，多变量 LSTM 模型在 MAE、MSE、RMSE 和 R² 等指标上均取得更优结果，说明气象变量能够为 PM2.5 浓度预测提供有效补充信息。
SHAP 可解释性分析进一步表明，历史 PM2.5 浓度是影响模型预测结果的最主要因素，风向、露点、气压和温度等气象变量也对预测结果具有一定贡献。同时，模型主要依赖最近若干小时的历史信息完成下一小时预测。
